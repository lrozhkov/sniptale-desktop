# Contributing to Sniptale Desktop

Sniptale Desktop does not currently accept external code contributions. Do not submit implementation patches or pull requests unless the repository owner explicitly requests them; unsolicited changes may be closed without review.

Public bug reports and product proposals must contain no credentials, personal data, private recordings, local paths, tokens, or undisclosed vulnerability details. Submission does not guarantee review, response, or implementation.

Do not publish suspected vulnerabilities in public issues. This repository does not yet publish a security-reporting channel.
