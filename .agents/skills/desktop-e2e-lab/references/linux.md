# Linux lanes

Use `linux-wayland` for GNOME Wayland and `linux-x11` for GNOME on Xorg; Xvfb is not an acceptance lane. Goldens provide local autologin, GDM, AppIndicator, portals, PipeWire/WirePlumber, virtual display and microphone paths, Chrome/Chromium, Firefox, AT-SPI, and key-based SSH.

Until a Sniptale Linux application exists, build the deterministic `sniptale-e2e-probe` `.deb`. Both lanes prove exact session type, screenshot portal, StatusNotifierItem/AppIndicator registration, synthetic output-to-microphone PCM loopback, non-empty screenshot, browsers, AT-SPI, and `.deb` install/purge.

Future `.deb` or AppImage adapters preserve controller, snapshot, transport, strict result, evidence, and receipt contracts. Add upgrade/repair and uninstall proof for packages; add integrity, direct launch, desktop integration, autostart, recovery, and clean removal for portable artifacts.
