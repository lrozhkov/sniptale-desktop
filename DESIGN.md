# Sniptale Desktop design entry

Read the [design index](docs/design/index.md) before product UI work. It routes the Desktop concept, current research, and delivery sequence.

Demonstrate a changed component and its required states in the design sandbox before composing it into settings or the tray menu. Use the same native component implementation for the Windows sandbox and product surface. A browser specimen alone does not prove Windows behavior.

The design system is being prepared. The [delivery plan](docs/design/delivery-plan.md) records what remains to implement and verify; the existence of these documents does not establish sandbox coverage or completion of the UI rewrite.
